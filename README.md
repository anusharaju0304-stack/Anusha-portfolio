# Anusha KJ — Student Portfolio

A responsive student developer portfolio built with plain HTML, CSS and JavaScript.

## Folder structure

```text
Anusha-Portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── images/
└── README.md
```

## Run in VS Code with Live Server

1. Extract `Anusha-Portfolio.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose the extracted `Anusha-Portfolio` folder.
4. Open the Extensions panel (`Ctrl + Shift + X`).
5. Search for **Live Server** and install it.
6. Open `index.html`.
7. Right-click inside the editor and select **Open with Live Server**.
8. Your portfolio opens in your browser. Save edits to see them refresh.

## Personalise before publishing

Some details were not available in the conversation history, so this starter website intentionally does not invent them.

- Replace the email placeholder in `index.html`.
- Add your GitHub and LinkedIn URLs in `js/script.js`.
- Add your education, certifications, internships, awards, hobbies and career goal once confirmed.
- Add your actual resume as `assets/resume.pdf` and then add a Resume button/link to the page.
- Review project descriptions to ensure they accurately reflect what you completed.
- Add your own photo in `assets/images/` if you wish.

## Notes

- No framework or package installation is required.
- The website uses HTML, CSS and vanilla JavaScript.
- Google Fonts are loaded online; system fonts will be used if unavailable.
- No actual resume, certification, internship or award is included because those details have not been supplied.
